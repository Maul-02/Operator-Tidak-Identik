# Operator !== (Tidak Identik/Strict Not Equal) di JavaScript

<h3> Pengertian </h3>
Operator !== adalah operator strict inequality (Tidak Identik) yang digunakan untuk membandingkan dua nilai. Operator ini akan menghasilkan nilai true jika kedua nilai tidak sama ATAU memiliki tipe data yang berbeda.
<br>
<br>
Berbeda dengan operator != (Tidak Sama), operator !== tidak melakukan konversi tipe data (type coercion) sebelum membandingkan. Artinya, perbandingan dilakukan secara ketat, baik dari segi nilai maupun tipe datanya.
